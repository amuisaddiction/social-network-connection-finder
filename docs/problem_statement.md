# Problem Statement

Social networks contain many users connected through friendships and relationships. As the number of users increases, manually determining how two users are connected becomes difficult.

The proposed Social Network Connection Finder models the network as a graph. Users are represented as vertices and relationships as edges. Breadth First Search is used to determine the shortest connection path between two users, while Depth First Search is used to explore the reachable network from a selected user.

The project demonstrates how graph data structures and traversal algorithms can solve a practical real-world problem.
