# Technology Stack

## Programming Language
**Python 3**

Reason:
- Easy to understand for a DSA mini-project
- Excellent built-in data structures
- Suitable for BFS and DFS
- Fast development

## GUI
**Tkinter**

Reason:
- Included with standard Python installations
- No heavy frontend setup
- Good enough for a clean academic desktop application

## Core Data Structures
- Dictionary
- List
- Set
- Queue using `collections.deque`
- Stack through list or recursion

## Algorithms
- Breadth First Search (BFS)
- Depth First Search (DFS)
- Shortest path reconstruction

## Storage
Initial version:
- In-memory graph

Optional:
- JSON file for persistence

## External Dependencies
Prefer zero external dependencies.

`requirements.txt` can therefore remain empty or contain only comments explaining that the project uses Python standard libraries.

## Development Environment
- VS Code
- Python extension
- Antigravity / Gemini Pro for development assistance

## Why This Stack?
The project is intended to demonstrate DSA rather than framework complexity. Using Python standard libraries keeps the implementation transparent and easy to explain during a viva.
